## 1. 流程（定稿）

```
新建项目
  ├─ 世界观 / 画风 / 画风参考图
  └─ 人物库
       ├─ 人设 tag（青年 / 老年 / 入魔 …）→ gpt-image-2 出一张三视图
       └─ 声音：上传参考音频 或 MiniMax 音色库（后台合成样本 wav）
新建章节 → 贴小说 → gpt-6-astra 拆分镜
  → 【人工审定分镜】
  → frame_mode = image：gpt-image-2 出首帧 → 【人工审定首帧】→ H3 出视频
  → frame_mode = text_only：直接 H3 出视频
  → 【验收】→ 不满意走 Regeneration
时间线拼接 → 导出 1080×1920 mp4
```

## 2. 模型分工与调用细节

### 2.1 文本 Agent · gpt-6-astra
- 接口：Responses API，`model: "gpt-6-astra"`，`text.format` 用 JSON Schema 强约束输出
- 输入：章节原文 + 世界观 + 画风 + 人物表（含每个人物全部 persona tag 与描述）+ 硬约束
- 输出：Shot 数组（字段见 v1 第 2 节），另加两个字段：
  - `frame_mode`：`image` | `text_only`。Agent 默认规则：有人物面部、需要精确构图或服装细节的镜头用 `image`；空镜、环境、转场、纯运镜、远景用 `text_only`。用户可逐镜切换。
  - `unit_id`：所属戏剧单元，用于前端把同一节拍的镜头分组显示
- 拆镜粒度规则（偏碎）：
  - 一句台词一镜；对话双方切反打，各自成镜
  - 一个动作一镜，反应另起一镜
  - 单镜目标 4–8 秒，上限 15 秒；超过必拆
  - 时长估算：中文台词 4 字/秒 + 动作预留 1–2 秒
- 回退：`gpt-6-astra` 不可用时（401 / 404 / 配额）自动切到配置的回退模型，UI 明示当前实际使用的模型
- 价格：$10 / $50 每百万 token（输入 / 输出）。一章 5000 字小说拆 30 镜，输入约 8k、输出约 6k token，单次约 $0.4

### 2.2 三视图 · gpt-image-2
- 接口：`images/edits`，参考图 = 画风参考图 + 同人物已有人设的三视图（保证跨人设同脸）
- 尺寸：1536×1024
- 提示词模板（刻意留白，不规定排版）：
  `[画风前缀]。人物设定图：[姓名]，[persona.description]。展示这个人物的整体造型，包含正面、侧面与背面，全身，干净背景。`
- 产出一张图，整张作为该 persona 的 sheet，同时作为后续首帧与视频的参考图

### 2.3 首帧 · gpt-image-2（仅 frame_mode = image）
- 接口：`images/edits`，参考图 = 出场人物所选 persona 的三视图 + 画风参考图，≤ 16 张
- 尺寸：1088×1920
- 提示：shot.frame_prompt，可编辑

### 2.4 视频 · MiniMax-H3
- `model: MiniMax-H3`，`resolution: 768P`，`ratio: 9:16`，`duration: shot.duration`
- content：
  - text：shot.video_prompt
  - first_frame：首帧（frame_mode = image 时）
  - reference_image：出场人物 persona 三视图，≤ 9 张
  - reference_audio：有台词人物的 voice.sample，≤ 3 段
- text_only 模式下 video_prompt 会由 Agent 写得更完整（补上场景、光线、人物外貌关键词），因为没有首帧兜底
- 轮询 10 秒；worker 并发默认 3

### 2.5 声音 · MiniMax T2A
- 上传：直接存为 sample
- 音色库：拉系统音色列表可试听；确定后用该 voice_id 合成一段固定台词（约 12 秒）存为 sample

## 3. 状态机（含 text_only 分支）

```
draft ──审定──▶ storyboard_approved
                   ├─ image ──▶ frame_generating ▶ frame_ready ──审定──▶ frame_approved ──▶ video_queued
                   └─ text_only ─────────────────────────────────────────────────────────▶ video_queued
video_queued ▶ video_generating ▶ video_ready ──验收──▶ done
                                       └─ 不满意 ▶ Regeneration / 退回上一闸门 / 切换 frame_mode
```

## 4. 视觉规范 · 制片手册

### 色板
| 用途 | 色值 |
|---|---|
| 页面底 | `#F4EFE6` 纸白 |
| 面板 / 卡片 | `#FBF8F2` |
| 主文字 | `#1F1B17` |
| 次文字 | `#6B6259` |
| 分割线 / 边框 | `#D9D0C3` |
| 强调（主按钮、当前镜头、进度） | `#B4302B` 朱砂红 |
| 强调压深（hover） | `#8E2521` |
| 状态：待审 | `#C58A2A` 赭黄 |
| 状态：生成中 | `#3D5A80` 靛青 |
| 状态：完成 | `#3F6B4A` 墨绿 |

### 字体
- 标题：霞鹜文楷 / 思源宋体 Bold（有装订本气质）
- 正文：思源黑体 Regular
- 时码、镜号、参数、费用：IBM Plex Mono

### 质感元素
- 章节页顶部用场记板式标题：项目名 · 章节号 · 镜头数 · 时长，等宽字排版，细线分隔
- 分镜表用印刷表格：细横线、无竖线、镜号左侧留装订边距
- 状态徽章是印章风格：方形、细边、字距拉开
- 按钮：矩形、1px 深边、无圆角或 2px 圆角，主按钮朱砂红实底
- 进度：横向细条 + 等宽时码，不转圈
- 阴影几乎不用，层次靠边线与纸色深浅

### 明确禁止
渐变、毛玻璃、发光、大圆角、Inter、emoji 图标、居中英雄区三列图标
