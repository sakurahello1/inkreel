## 0. 一句话流程

新建项目（世界观 + 画风 + 人物库）→ 新建章节 → 贴小说 → Agent 出分镜表 → **人工审定分镜** → gpt-image-2 出首帧 → **人工审定首帧** → MiniMax-H3 出 768P 视频 → 验收 → 时间线拼接导出。

两道人工闸门是硬性的，任何镜头不经审定不会自动花钱。

---

## 1. 模型分工

| 环节 | 模型 | 说明 |
|---|---|---|
| 分镜拆解、首帧提示词 | 文本 Agent（默认 Claude，可换 MiniMax 文本模型） | 输出结构化 JSON，不是自由文本 |
| 人物三视图 | gpt-image-2 `images/edits` | 带画风参考图 + 人物描述，最多 16 张参考 |
| 分镜首帧 | gpt-image-2 `images/edits` | 带该镜出场人物的三视图 + 画风参考，尺寸 1088×1920（9:16，边长需为 16 倍数） |
| 视频 | MiniMax-H3，768P | 首帧 + 人物参考图 + 参考音频 + 文本提示 |
| 视频微调 | MiniMax-H3 Regeneration | 以已生成视频为 base，一句话改 |
| 现成音色 | MiniMax T2A 系统音色 | 合成一段 10–15 秒样本 wav 作为 H3 的 reference_audio |

> 注：H3 分辨率只有 768P / 2K 两档，没有 720P。按你的判断直接出 768P。

## 2. 项目结构与数据模型

```
Project
 ├─ world          世界观（时代、地理、规则、禁忌）
 ├─ style          画风描述 + 画风参考图 1–4 张（所有生图调用统一前置）
 ├─ characters[]   人物
 │    ├─ 基础信息：姓名、年龄、身份、性格、口头禅、关系
 │    ├─ personas[]   人设（同一人物可有多套，用 tag 区分）
 │    │     ├─ tag         例：青年 / 老年 / 正常 / 入魔 / 婚服
 │    │     ├─ description 该人设下的外貌、服装、标志物
 │    │     ├─ sheet       三视图（正 / 侧 / 背，gpt-image-2 生成，可重生成、可上传替换）
 │    │     └─ prompt      生成三视图用的提示词，可编辑
 │    └─ voice
 │          ├─ source     upload | minimax_system
 │          ├─ voice_id   系统音色 id（source=minimax_system 时）
 │          └─ sample     最终给 H3 用的参考音频文件（上传的原文件，或系统音色合成的样本）
 └─ chapters[]     章节
      ├─ source_text   原文小说
      └─ shots[]       分镜
```

### Shot（分镜）字段，Agent 必须全部填满

| 字段 | 类型 | 说明 |
|---|---|---|
| index | int | 镜号 |
| scene | string | 场景：地点、时间、天气 |
| shot_size | enum | 大远景 / 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 |
| camera | string | 运镜：固定 / 推 / 拉 / 摇 / 移 / 跟 / 升降 / 手持，含起止 |
| duration | int 4–15 | 秒，按台词字数与动作估算，中文按 4 字/秒 |
| characters | [{character_id, persona_tag}] | 出场人物 + 本镜所用人设 tag |
| dialogue | [{character_id, line, tone}] | 台词，含语气 |
| emotion | string | 本镜情绪基调与人物内心 |
| action | string | 人物动作与走位 |
| sound | string | 环境音、音效提示 |
| frame_prompt | string | 首帧提示词，给 gpt-image-2，可人工改 |
| frame_refs | [persona_sheet_id] | 首帧参考图，默认 = 出场人物所选人设的三视图 |
| video_prompt | string | 视频提示词，给 H3，可人工改 |
| status | enum | 见第 4 节状态机 |

## 3. Agent 分镜流程（细）

**输入**
1. 章节原文
2. 项目世界观 + 画风描述
3. 人物表：每个人物的基础信息 + 所有 persona tag 及其描述（Agent 需要知道有哪些 tag 可选）
4. 硬约束：单镜 4–15 秒；出场人物只能从人物表选；每个出场人物必须指定 persona_tag；竖屏 9:16 构图

**步骤**
1. **切段**：按情节节拍把原文切成若干"戏剧单元"（一个动作、一句关键对白、一个反应）。
2. **拆镜**：每个单元拆成 1–3 个镜头，估时长，超过 15 秒强制拆分。
3. **选人设**：根据文中时间线和状态词（"多年后""走火入魔"）为每个出场人物选 tag；无法判断时选默认 tag 并打标 `needs_review`。
4. **写首帧提示词**：模板固定顺序
   `[画风前缀] + [场景/光线/天气] + [人物：外貌关键词来自 persona.description，姿态、表情、位置] + [景别/机位/焦段感] + [竖屏 9:16 构图要求] + [负面：不要文字、不要水印]`
5. **写视频提示词**：
   `[镜头描述与运镜] + [人物动作] + [台词，标明说话人与语气] + [情绪] + [环境音] + [保持人物外貌与参考图一致]`
6. **输出**：严格 JSON 数组，前端渲染成分镜表。校验失败（缺字段、tag 不存在、时长越界）自动回炉重试一次，仍失败则标红交人工。

**Agent 可被再次调用**：选中若干镜头说"合并""拆细""改成特写""台词换成……"，只重写选中的镜头，其余不动。

## 4. 分镜状态机

```
draft ──审定──▶ storyboard_approved
                   │  生成首帧
                   ▼
              frame_generating ──▶ frame_ready ──审定──▶ frame_approved
                                       │ 不满意                 │ 提交
                                       ▼                        ▼
                                  改提示词/重生成          video_queued
                                                               │
                                                               ▼
                                                        video_generating ──▶ video_ready ──验收──▶ done
                                                                                  │ 不满意
                                                                                  ▼
                                                                          Regeneration 或 退回 frame_approved
```

- 每个 shot 独立走状态机，章节页可批量操作（全选审定、全选生成首帧）。
- 每一次生成（三视图、首帧、视频）都记录：提示词快照、参考资产 id、模型、耗时、费用。旧版本保留，可回滚。
- 任何审定前的修改（改提示词、换 tag、换参考图）都会把状态退回到对应闸门之前。

## 5. 页面与交互（细）

### 5.1 项目页 · 三个 tab

**世界观**：两个大文本区（世界观 / 画风），画风参考图上传区。保存后所有生图提示词自动带上画风前缀。

**人物库**
- 左列人物列表，右侧人物详情。
- 详情顶部是基础信息表单。
- 中部是人设区：每个 persona 一张卡，卡上是 tag 胶囊 + 三视图横排三格 + 「重生成」「上传替换」「编辑提示词」。
- 「新增人设」弹窗：填 tag 和描述，点生成 → 调 gpt-image-2，参考图 = 画风参考图 + 同人物已有人设的正面图（保证同一人不同阶段像同一个人）。
- 底部声音区：单选「上传参考音频」/「MiniMax 音色库」。选音色库时弹出列表，可试听；确定后后台合成样本 wav 存为 sample。

**章节**：章节列表，新建即进入空白分镜页。

### 5.2 分镜页（核心）

三栏布局：
- **左栏**：原文小说。贴入后顶部出现「让 Agent 拆分镜」按钮。之后原文按镜头高亮，点某段跳到对应镜头。
- **中栏**：分镜表。每镜一行，可展开。行内直接显示：镜号、时长、景别、出场人物头像（带 tag 角标）、台词摘要、状态徽章。展开后所有字段可编辑，首帧提示词和视频提示词各一个文本框。
- **右栏**：当前镜头的预览区。首帧未生成时显示参考图缩略（人物三视图）；有首帧后显示首帧大图；有视频后显示视频播放器。下方是操作按钮，随状态变化：审定分镜 → 生成首帧 → 审定首帧 → 生成视频 → 验收 / 重生成。

顶部工具条：批量选择、批量审定、批量生成、本章费用累计、Agent 对话入口（对选中镜头下指令）。

### 5.3 时间线页

已验收镜头按镜号自动排入，可拖拽调序、裁头尾、加淡入淡出、加字幕（台词自动填入）、加 BGM。导出 1080×1920 mp4。

## 6. 关键调用细节

**三视图（gpt-image-2）**
- 接口：`images/edits`，参考图 = 画风参考图 + 已有人设正面图（若有）
- 提示：`[画风前缀] 人物设定三视图，正面/侧面/背面并排，全身，纯色背景，同一人物同一服装，[persona.description]`
- 尺寸 1536×1024 横图，生成后前端按三等分裁切成三张，也允许直接用整张

**首帧（gpt-image-2）**
- 参考图 = 出场人物所选 persona 的三视图（每人 1–3 张）+ 画风参考图，总数 ≤ 16
- 尺寸 1088×1920
- 提示 = shot.frame_prompt

**视频（MiniMax-H3）**
- model: `MiniMax-H3`，resolution: `768P`，ratio: `9:16`，duration: shot.duration
- content:
  - text: shot.video_prompt
  - first_frame: 首帧图
  - reference_image: 出场人物 persona 正面图（≤9 张）
  - reference_audio: 出场且有台词的人物的 voice.sample（≤3 段）
- 轮询 10 秒一次；worker 并发数可配，默认 3

**重生成（H3 Regeneration）**
- base_video = 上一版视频，text = 用户一句话修改意见

## 7. 单镜成本（估）

| 项 | 数量 | 估价 |
|---|---|---|
| 首帧 | 1–2 次 | 约 $0.05–0.2 |
| H3 768P 12 秒 | 1 次 | 待官方计费页确认，量级约 $1 上下 |
| 重生成 | 平均 0.5 次 | 同上折半 |

一章 10 镜约 $10–15。三视图是一次性成本，每个人设约 $0.1–0.3。

## 8. 技术架构（沿用 v0，微调）

- Next.js 15 + TypeScript + Tailwind v4 自研组件
- Postgres + Prisma；对象存储放图片、音频、视频
- Worker：BullMQ + Redis，三条队列：`image`、`video`、`voice`
- Provider 适配层：`OpenAIImageProvider`、`MiniMaxVideoProvider`、`MiniMaxSpeechProvider`、`TextAgentProvider`
- Agent 输出走 JSON Schema 校验（zod），不合规不入库
