# 方案：说书模式（图文有声 · PPT 式）

> 状态：计划稿，未开工。2026-09-19。

## 一、定位

同一个工作台，项目级选「制作类型」：

| | 短剧 drama（现有） | 说书 narrated（新） |
|---|---|---|
| 一页/一镜是什么 | 一段 4–15 秒的视频 | 一张图 + 一段配音 |
| 时长由谁决定 | 拆镜 Agent 估 | 配音音频长度 |
| 视频模型 | 需要 | 不需要 |
| 一章成本 | 促销价 $2–3，原价 $6–10 | **< $1** |
| 一章出片时间 | 一小时级 | 分钟级 |
| 展示方式 | 成片 | 字幕式 / galgame 式（可扩展） |

复用：世界观、人物库、场景库、道具库、音乐库、章节与原文、拆分 Agent 骨架、资产出图（ImageJob）、版本库与血缘指纹、时间线裁切、ffmpeg 导出骨架、访问控制与部署。
新增：拆页 Agent、声音选角（人工确认闸门）、TTS 任务、页预览播放器、说书渲染器、立绘。

## 二、一章的流程

```
原文 ──拆页 Agent──▶ 页（每页：画面提示词 · 旁白 · 台词[说话人/语气/表情] · 出场人物 · 场景）
                        │
资产库（三视图 · 场景图 · 道具图 · 画风）──▶ 页图（gpt-image，复用首帧管线；可上传 / 重画 / 版本）
                        │
声音选角（Agent 推荐 → 人工试听确认 · 硬闸门）──▶ 配音（每条旁白 / 台词一次 TTS，带时间戳）
                        │
浏览器内预览（图 + 音频 + 展示层，不用导出）──▶ 导出（Ken Burns · 页间叠化 · 字幕或对话框 · BGM · 片尾）
```

### 1. 拆页

- **页的定义**：画面不变的一段叙述。一段原文可能是 0 页（并入上一页）、1 页或多页；目标每页 10–25 秒（≈ 60–150 字配音）。
- 每页输出：`image_prompt`、`narration`（旁白，第三人称叙述与内心独白）、`lines[]`（`speaker / line / tone / expression`）、`characters[]`、`scene`、`layout` 提示（谁在画面上、立绘放左还是右）。
- 复用现有拆镜 Agent 的任务骨架（`ChapterStoryboardJob`）：换 system prompt 与 JSON schema，分镜组照旧（配乐连续段落还是按组）。
- 人可以拆页 / 合并页（复用现有「拆成两镜」「与下一镜合并」）。

### 2. 页图

- 直接走现有首帧管线：场景图 + 人设三视图 + 道具图 + 画风参考 → gpt-image。说书没有视频模型的约束，图片模型的质量是纯优势。
- 画幅：项目级 16:9 或 9:16；galgame 惯例是横屏。
- 版本、上传、重画、过期都是现成的。

### 3. 声音选角（新，硬闸门）

- **声音库**：MiniMax `GET /v1/get_voice`（系统音色 + 已克隆音色），每个音色缓存一段固定试听句。
- **Agent 选角**：对每个开口的角色 + 旁白，按人设描述（性别 / 年龄 / 性格 / 语速）从库里挑 **3 个候选**并给理由，同时建议 `speed / pitch / emotion` 默认值。
- **试听页**：一行一个角色，候选用**该角色自己的一句台词**合成 3 秒试听（几乎不花钱），人工点「确认」；也能手动换音色、上传样本克隆（MiniMax 快速克隆 $1.5/音色，首次合成时扣）。
- **闸门**：所有开口角色 + 旁白都确认之前，「生成配音」按钮禁用。确认记在 `Character.voiceId / voiceConfirmedAt`，旁白记在 `Project.narratorVoiceId`。角色的人设描述改了 → 提示"要不要重新选角"，但不强制。

### 4. 配音

- 每页每条 utterance（旁白 / 台词）一次 TTS：MiniMax `POST /v1/t2a_v2`，`speech-2.8-hd`（$100 / 百万字）或 `turbo`（$60）；`subtitle_enable + subtitle_type=sentence|word` 直接拿到毫秒级时间戳，**不需要再走 Whisper 对齐**。
- 每条一个 `Generation(kind=voice)`，有版本：能重配、换语气、换语速、单条重来。
- 页时长 = Σ 各条时长 + 条间停顿（可调，默认 0.4 s）+ 页尾留白（默认 0.8 s）。
- 输入指纹：文本 + voiceId + 参数 → 改一个字只重配这一条。

### 5. 预览（新）

浏览器内播放器：按页顺序播图 + 逐条播音频 + 实时渲染展示层（字幕 / 对话框 / 立绘）。说书的产物是「图 + 音 + 版式」，HTML 能原样渲染，所以**改样式、改停顿、换表情都不用导出就能看**。

### 6. 导出

ffmpeg，一页一段：
- 图：`zoompan` 缓慢推拉（Ken Burns，可关）；页间 `xfade` 叠化或黑场
- 音：该页各条 utterance 按停顿拼接；BGM 沿用现有连续段落逻辑，旁白时自动压低（sidechain 或简单 ducking 包络）
- 展示层：
  - 字幕式：现有 ASS 管线，时间戳来自 TTS；旁白与台词两种样式（旁白浅色无名字，台词带说话人）
  - galgame 式：对话框 + 名牌为透明 PNG `overlay`；文字用 ASS `\k` 卡拉 OK 标签做逐字出现；立绘为透明 PNG `overlay`，讲话方原色、非讲话方压暗（`colorchannelmixer`）
- 片尾字卡照旧

## 三、展示样式

| 样式 | 画面 | 文字 | 备注 |
|---|---|---|---|
| **字幕式** subtitle | 全屏页图 | 底部字幕；旁白/台词样式区分 | 现有能力，M1 就有 |
| **galgame** | 页图作背景，讲话角色立绘在左/右 | 底部半透明对话框 + 名牌，逐字打出；旁白用无名牌的居中框 | 需要立绘 |
| 半身像变体 | 同上，立绘改成对话框左侧头像框 | 同上 | galgame 的子选项 |
| 有声书 | 封面 + 波形 / 章节名 | 无或少 | 后续 |

- 样式是项目默认 + 章节覆盖；参数：字体、字号、框透明度与配色、立绘位置、打字速度、Ken Burns 强度。
- **立绘**：每个人设 tag 一套，透明底站姿正面，2–4 个表情（平静 / 笑 / 惊 / 哭）。用三视图作参考、gpt-image-2.5 `background=transparent` 生成；也允许手动上传。

## 四、数据模型

```
Project   + kind ("drama" | "narrated")  + presentStyle ("subtitle" | "galgame")
          + narratorVoiceId  + styleConfig JSON
Shot      复用为「页」：frameMode 固定 image，无视频字段参与；+ narration String
          dialogue 项 + expression（立绘表情）
Utterance 新表：shotId · order · kind(narration|line) · characterId? · text · emotion · speed
          · voiceId · assetId(音频) · duration · timestamps JSON · inputHash · status
Character + voiceId · voiceProvider · voiceParams JSON · voiceConfirmedAt
Persona   + sprites Sprite[]
Sprite    新表：personaId · expression · assetId
Generation.kind 新增 voice · sprite · cast
```

不动现有短剧数据；`kind=drama` 的项目行为完全不变。

## 五、任务（jobs/）

| 任务 | 说明 |
|---|---|
| `chapter.pages` | 拆页 Agent；复用 storyboard 任务骨架，新 prompt + schema |
| `shot.frame` | 页图，原样复用 |
| `persona.sprite` | 透明底立绘，三视图作参考 |
| `project.cast` | Agent 选角 → 候选 + 试听样本 TTS |
| `utterance.tts` | 单条配音；`chapter.voices` 批量串行入队 |
| `chapter.export` | 按 `Project.kind` 分流到说书渲染器 |

## 六、界面

- 新建项目时选类型；说书项目的章节页三栏改为：**左** 页列表（缩略图 + 旁白首句 + 时长）· **中** 页编辑器（画面提示词 / 旁白 / 台词表：说话人、语气、表情、立绘位置）· **右** 页预览（HTML 实时渲染的展示层 + 逐条音频播放 / 重配 / 换语气）。
- 项目级「声音选角」页：角色 × 候选表格，试听、确认、替换、克隆。
- 工具条：拆页 · 出图 · 选角 · 配音 · 预览 · 导出。
- 章节级「预览」全屏播放器。

## 七、成本（一章 3000 字 ≈ 25 页 ≈ 8 分钟）

| 项 | 估算 |
|---|---|
| 页图 25 张（gpt-image-2.5 low–medium） | $0.15–0.75 |
| 配音 3000 字（speech-2.8-hd） | $0.30（turbo $0.18） |
| 选角试听（每角色 3 条 × 20 字） | ≈ $0.01 |
| 立绘（4 角色 × 4 表情，一次性） | ≈ $0.5 |
| **合计** | **约 $0.5–1.5 / 章**，出片几分钟 |
